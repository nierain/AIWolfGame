# AIWolfGame 项目记忆（精简版）

> 详细流程见同目录 `PROCEDURES.md`：回滚对局、桥接骑士预写、自动推进、provider 矩阵、环境坑、已知未修。

## 铁律

1. **信息隔离**：AI 决策只能来自该座位的 `get_visible_state`；Worker 本人可知道全场底牌，
   但**禁止向真人播报**电脑身份、查验结果、夜间私有行动、狼队友名单——只播报公开动作
   （发言、投票、上警、决斗、公开死亡）。
2. **一次行动 = 一个独立决策者**：绝不批量给多个座位写发言（2026-09-15 真人反馈"太呆"的根因：
   同一时刻同一套判据产出 11 段话，票型假到 10.5:1）。每个座位先用自己 `private` 里的信息；
   批量投票要逐座位回到它自己的公开立场核对。
3. **不翻牌**：只有骑士决斗、狼美人死亡、本人自认会公开身份；**被放逐、被刀都不公示**。
4. **改代码必须重启服务**；只改存档不用重启（`load_state()` 每次请求都读盘）。
5. 引擎只裁决行动意图的合法性，技能/投票/死亡/警徽/胜负由确定性规则决定；真人阶段必须暂停。

## 陪玩约定

- 真人出局后仍由他指挥狼队（rain 定）；好人阵营我按各自视角独立打，不向他透露信息。
- Agent 只能被"收到一条消息"触发；可行节奏 = 真人做完自己那一回合发一句"继续"，
  我把之后的 AI 动作一口气打完，直到下一个真人回合。
- 排查环境优先 `/api/health`；反复读身份表对判断没帮助，还容易顺手说漏嘴。
- 本机没装 agent-browser，改页面后用 Node + DOM 桩验证（见 PROCEDURES §6）。
