## 陪玩环境搭建（AIWolfGame 桥接模式）

- 需求：用户想用本 Agent 代替 Codex 驱动 11 个电脑玩家，与真人（称呼 rain）对战。
- 服务：`panel_game.py --provider codex`（文件桥接）跑在 http://127.0.0.1:18765。
  - 端口 8765 被系统里另一个服务占用（返回 404），不要用；18765 可用。
  - 用 `tools/launch_panel.py start` 或 `启动狼人杀-桥接.bat` 启动。
- Worker 端工具：`tools/bridge_worker.py`（pending / wait / show / reply / schema / stats），
  只读 tasks 里的 `visible_state`，写回前校验字段与目标。
- 本机限制：bash 缺 coreutils（`ls`/`cat`/`tail` 不存在，用 Read/Glob 或 python）；
  PowerShell 工具沙箱报 Access Denied 不可用；wmic 被安全策略禁用；
  tasklist/netstat 输出是 GBK，需 `decode('gbk','replace')`。
- 用 `run_in_background` 起的服务能跨对话轮次存活。
